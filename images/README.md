# Images

Reference images for the knowledge base: plant identification (including deadly lookalikes side by side), first aid, knots, fire, shelter, and navigation. Every image is listed in [`manifest.json`](manifest.json) with a searchable caption, alt text, tags, region, risk level, and license. See [CONTRIBUTING.md](../CONTRIBUTING.md#images) to add one.

> ⚠️ A photo alone is never enough to identify a plant as safe to eat. Use these images to learn features and lookalikes, and confirm in person with an expert while you can.
